# afu-remote

Base images and installers for devices that run afu-remote.

- [`r2t2/base-image/`](r2t2/base-image/) SD card image for the DARC R2T2: boot chain, kernel 6.12
  and a minimal Debian, without R2T2 software. Images are attached to the releases.

The installer for the R2T2 software (hardware layer, `r2t2sdr`, afu-remote) follows.
